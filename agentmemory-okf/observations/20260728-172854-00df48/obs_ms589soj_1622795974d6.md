# Summary

Web extract tool encountered an error when attempting to fetch content from Brave Search. The limitation of the Brave Search backend as a search-only backend cannot be bypassed without configuring the web.extract_backend property.

## Facts
- web_extract_tool: failed to extract content from Brave Search (https://substack.com/@yourmeditation/note/c-292717360)
- required web.extract_backend property, setting web.extract_backend to firecrawl, tavily, exa, or parallel is necessary for successful extraction
