# Summary

Xcode 27 does not support third-party agents like Kilo directly, but uses the Model Context Protocol (MCP) bridge to expose its tools. Users must enable this feature and register their external agent accordingly.

## Facts
- xcode-ai-agents is a third-party agent for connecting external AI coding agents to Xcode 27, enabling read, build, and edit capabilities.
