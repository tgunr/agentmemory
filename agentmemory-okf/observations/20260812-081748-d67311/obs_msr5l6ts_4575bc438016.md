# Summary

This command allows for reading from a running process with partial output support. It can be used with offset and length parameters to read specific parts of the output. The command also provides detailed timing information when verbose_timing is enabled.

## Facts
- Use offset and length parameters to read from a running process with file-like pagination support.
- Partial output reading is supported with configurable 'fileReadLineLimit' setting.
