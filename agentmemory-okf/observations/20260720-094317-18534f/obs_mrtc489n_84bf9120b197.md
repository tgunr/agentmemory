# Summary

Viewed integration skill documenting rules for connecting AgentMemory with Hermes Agent. Covers secret resolution, session registration flow, title synchronization, profile configuration requirements, and known pitfalls with stale session data overriding config changes.

## Facts
- AGENTMEMORY_SECRET must be loaded from os.environ with fallback to ~/.agentmemory/.env to avoid 401 errors
- Hermes session IDs (YYYYMMDD_HHMMSS_hash format) must be registered via POST /agentmemory/session/start before sending observations
- Session titles must be read from ~/.hermes/state.db and pushed via POST /agentmemory/session/update for UI display
- AgentMemory UI runs on port 3113
- agentmemory profile requires plugins: kilocode-provider and custom-provider enabled
- Provider must be named "kilocode" not "kilo" to match credential pool
- hermes config set stores list values as YAML strings instead of lists - requires manual yaml.safe_load/dump fix
- Stale session model_config in state.db overrides config.yaml settings when TUI resumes session
