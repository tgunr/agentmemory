# Summary

Created a launcher script that works around EufyMake Studio crashing on macOS Tahoe developer betas by forcing the GPU process to use SwiftShader software rendering instead of Apple Metal. The script also clears stale CEF singleton locks left by hard kills to prevent false "instance already running" crashes.

## Facts
- Created bash script at /Applications/eufyMake Studio (Safe).app/Contents/MacOS/eufyMake-Launcher (1127 bytes)
- Script removes stale CEF singleton locks (SingletonLock, SingletonSocket, SingletonCookie, LOCK) to allow relaunch after hard kills
- Exports SENTRY_DUMP_STDOUT=1 for debug output
- Passes Chromium flags: --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist --disable-gpu-compositing
- Uses SwiftShader for software WebGL rendering to avoid Apple Metal crashes on macOS 27 Tahoe
