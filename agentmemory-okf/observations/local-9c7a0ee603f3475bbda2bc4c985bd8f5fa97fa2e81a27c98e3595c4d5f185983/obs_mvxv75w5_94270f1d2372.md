# Summary

The session_search tool is used to search or read past Hermes conversations. It provides four shapes: query as discovery, session_id + around_message_id as scroll, session_id alone as read, and no args as browse recent sessions.

## Facts
- Search query can be keywords, phrases, or boolean expressions.
- Session_id and around_message_id can be used for scroll and read operations.
