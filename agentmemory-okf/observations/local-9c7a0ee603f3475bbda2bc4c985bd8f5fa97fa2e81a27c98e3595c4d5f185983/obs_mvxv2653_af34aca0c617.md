# Summary

xAI's Grok Bot is an AI agent product that allows users to create named helpers, called Bots, that each have a job and keep working in the background. The product offers seamless teamwork between agents and has a great application experience on the phone and various computers. Grok Bot's documentation has undergone changes, with the latest updates naming no model and offering no model picker, prompting users to use the best back-end model for each task.
