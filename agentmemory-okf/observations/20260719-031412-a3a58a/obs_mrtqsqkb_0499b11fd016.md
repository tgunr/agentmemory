# Summary

The integration with Hermes Agent requires careful configuration and proper handling of secrets, sessions, and title sync. The plugin must robustly load AGENTMEMORY_SECRET from ~/.agentmemory/.env as a fallback if the env var is missing, to avoid 401 Unauthorized errors. Moreover, custom session IDs generated by Hermes TUI MUST be explicitly registered via POST /agentmemory/session/start before sending observations.

## Facts
- AGENTMEMORY_SECRET must be robustly loaded from ~/.agentmemory/.env as a fallback if the env var is missing.
- Hermes TUI generates custom session IDs (e.g., YYYYMMDD_HHMMSS_hash) that MUST be explicitly registered before sending observations.
