# Summary

The BlueBubbles sender records outbound message GUIDs and normalized chat/text combinations after a successful API request. These bounded caches allow the inbound webhook handler to discard echoes of messages sent by the agent and avoid self-loop re-ingestion.

## Facts
- Text messages are posted to /api/v1/message/text; private API replies add method, selectedMessageGuid, and partIndex fields when enabled and connected.
- The returned guid or messageGuid is stored in _sent_guids with a UTC timestamp and bounded by _sent_guids_max.
- Normalized outbound text is stored in _sent_texts under both chat_id and guid keys so inbound webhook echoes can be detected regardless of chat resolution.
- A successful request creates SendResult(success=True, message_id=str(msg_id), raw_response=res), defaulting the message ID to "ok" when absent.
