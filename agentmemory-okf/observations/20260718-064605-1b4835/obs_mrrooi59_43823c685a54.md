# Summary

This reference document outlines the mechanism for locking down the BlueBubbles gateway to specific allowed phone numbers. It details the authorization flow in `authz_mixin.py`, the E.164 format of user IDs, required `.env` variables, and verification steps using synthetic webhooks to the LAN IP.

## Facts
- Authorization logic located in `gateway/authz_mixin.py::_is_user_authorized`
- Env vars `BLUEBUBBLES_ALLOW_ALL_USERS` and `BLUEBUBBLES_ALLOWED_USERS` control access
- `user_id` derived from `record["handle"]["address"]` in `gateway/platforms/bluebubbles.py::_handle_webhook`
- Webhook endpoint listens on LAN IPv4 (e.g., 192.168.88.7:8645), not localhost
- Gateway must be restarted via Terminal.app to apply `.env` changes
