# Summary

Extended the existing GUID-based self-loop guard with text-based detection to catch BlueBubbles webhook echoes on Tahoe when helper_connected=false. The platform re-webhooks outbound replies as fresh inbound events, potentially causing infinite loops. By tracking recent sent message texts alongside GUIDs, both echo paths are now blocked.

## Facts
- Added self._sent_texts OrderedDict to track (chat_id, normalized_text) of sent messages
- Added self._sent_text_window = 30.0 seconds for text-based echo detection window
- Added _norm_text() static method for case/space/format agnostic text normalization
- Updated comment explaining echo can arrive on \"any;-\" channel OR real chat GUID
