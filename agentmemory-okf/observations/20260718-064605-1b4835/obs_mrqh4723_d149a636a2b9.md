# Summary

Viewed the macos-integrations skill which provides comprehensive documentation for Apple ecosystem integrations. The skill covers CLI tools (imsg, memo, remindctl), BlueBubbles gateway for programmatic iMessage access, launchd service management with documented pitfalls, and a mode-based service manager pattern using rumps for menu bar apps. This serves as the authoritative reference for all macOS-specific automation tasks.

## Facts
- Skill covers 7 integration areas: iMessage/SMS, BlueBubbles Gateway, Apple Notes, Apple Reminders, FindMy, macOS Launchd, Computer Use, Menu Bar Apps
- iMessage via `imsg` CLI (brew install steipete/tap/imsg), requires Full Disk Access
- BlueBubbles gateway runs on localhost:1234, webhook on :8645, authoritative config source is server's config.db (not .env)
- Apple Notes managed via `memo` CLI; Reminders via `remindctl`
- Launchd recent learnings: emoji menu bar titles may render invisible, write_file fails through volume symlinks (use terminal/heredoc), terminal(background=true) SIGTERMs GUI apps, launchctl bootstrap exit 78 needs proper domain + logging
- Menu bar apps use `rumps` Python library with mode-based service manager pattern (YAML-defined work modes: AI, Dev, Design, Comms, Minimal)
- ModeSwitcher project located at /Volumes/alpha/sources/mode-switcher/
- rumps pitfall: rumps.separator is NOT MenuItem.set_separator()
- BlueBubbles health probe script: scripts/bluebubbles-diag.sh
- BlueBubbles gateway wiring: hermes gateway run + hermes pairing approve bluebubbles + BLUEBUBBLES_ALLOW_* auth vars
