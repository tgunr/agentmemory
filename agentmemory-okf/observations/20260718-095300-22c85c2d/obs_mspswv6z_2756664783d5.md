# Summary

The plugin reads the title from Hermes's ~/.hermes/state.db and sends it. The agentmemory profile must have specific provider and plugin configuration to route API calls correctly.

## Facts
- AGENTMEMORY_SECRET must be loaded from ~/.agentmemory/.env as a fallback if the env var is missing
- Hermes TUI generates custom session IDs (e.g., YYYYMMDD_HHMMSS_hash) that MUST be explicitly registered via POST /agentmemory/session/start before sending observations
