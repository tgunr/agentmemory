# Summary

The AgentMemory integration with Hermes Agent requires several steps for correct registration and title sync. The plugin must load AGENTMEMORY_SECRET from the environment variables and ~/.agentmemory/.env, and generate custom session IDs. Additionally, it needs to update the session ID and title via POST requests.

## Facts
- Native plugins MUST robustly load AGENTMEMORY_SECRET from ~/.agentmemory/.env as a fallback if the env var is missing
- Hermes TUI generates custom session IDs (e.g., YYYYMMDD_HHMMSS_hash)
