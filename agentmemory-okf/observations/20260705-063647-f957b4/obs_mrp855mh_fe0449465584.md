# Summary

The project store implements immediate UI feedback when adding a folder, while preserving rollback behavior if persistence fails. Primary-folder changes also update the cached tree path, and a nearby helper supports safe navigation when deleting a project containing the currently open session.

## Facts
- addProjectFolder snapshots project state, trims the supplied path, and optimistically appends a non-duplicate folder to the matching project.

- The projects.add_folder gateway request runs through persistOrRollback, followed by reconcileProjects to load backend-computed repository seeding and session regrouping.
