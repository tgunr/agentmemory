# Summary

Xcode 27 ships two ways to bring an external coding agent into your workflow:
 In-IDE ACP agent — registered in **Settings → Intelligence → Agents → \"Add an Agent…\"**
 External MCP client — any MCP-aware agent connects to Xcode's MCP server at `xcrun mcpbridge` over stdio.

## Facts
- Kilo is NOT a built-in provider and must be registered manually
- ACP version mismatch can occur if installing with npm or homebrew
