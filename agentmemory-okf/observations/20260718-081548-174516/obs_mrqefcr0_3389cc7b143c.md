# Summary

A technical reference document was created explaining wood preparation requirements for UV printing workflows. The guide emphasizes that sealing raw wood prevents ink absorption and ensures proper print quality, and that using dewaxed clear shellac is critical to avoid adhesion issues with subsequent epoxy flood coats.

## Facts
- File written to references/wood.md in uv-printing skill directory
- Recommends dewaxed clear shellac (2-lb cut) as sealer for UV printing on maple
- Explains porosity causes washed-out colors, soft detail, and uneven tone
- Warns waxed shellac causes fish eyes and poor epoxy wet-out under flood coat
- Distinguishes sealer role (print quality) from epoxy role (protection/finish)
- Advocates sealing both faces to control warping during print + epoxy cycle
