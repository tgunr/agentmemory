# Summary

Updated the uv-printing skill documentation with critical wood preparation warnings. Without proper sealing, UV ink will absorb into raw wood causing muted, blotchy artwork. Using waxed shellac creates adhesion problems with epoxy flood coats, requiring de-waxed clear shellac instead.

## Facts
- Added bullet point about sealing wood before UV print to prevent ink absorption into grain
- Added bullet point about waxed/colored shellac causing fish eyes and poor epoxy wet-out
- Specified DEWAXED clear shellac (Zinsser SealCoat) as required solution
- Clarified that shellac "#2" specification means 2-lb cut ratio, not waxed product
- Referenced references/wood.md for seal procedures
