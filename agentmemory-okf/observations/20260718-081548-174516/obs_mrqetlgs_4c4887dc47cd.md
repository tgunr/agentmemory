# Summary

Updated the PROJECT.md file to specify exact shellac formulation for sealing CNC project. Changed from generic "#2 shellac" to detailed specification of de-waxed super-blonde shellac flakes with mixing ratio. This ensures epoxy compatibility and prevents finish defects like fish eyes.

## Facts
- File: /Volumes/projects/CNC/Eagle Plaque/PROJECT.md
- Changed sealant from "#2 shellac" to "De-waxed super-blonde shellac flakes, cut to 2-lb"
- Mixing ratio: 4 fl oz denatured alcohol per 1 oz flake by weight
- Applied both sides, sanded back with 240 grit
- Dewaxed shellac is epoxy-safe and prevents fish eyes
- Super-blonde shellac provides no tint on print face
- Warning: Do not use waxed/amber shellac (e.g., Zinsser Bulls Eye 701) or colored craft shellac under epoxy
