# Summary

The Kilo AI Gateway supports multiple authentication methods depending on your use case. API key authentication, organization tokens, and Bring Your Own Key (BYOK) are the primary methods. ByOK lets you use your own provider API keys with the Kilo AI Gateway.

## Facts
- Organization tokens are scoped with a 15-minute expiry and enforce the organization's policies, including model allow lists, provider restrictions, and per-user spending limits.
- BYOK lets you use your own provider API keys with the Kilo AI Gateway. When a BYOK key is configured, requests are sent to the provider using your key.
