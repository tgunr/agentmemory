# Summary

This documentation explains the concept and usage of profiles in the Hermes agent, which allows for independent agents on the same machine.

## Facts
- Agents run on the same machine with their own config, API keys, memory, sessions, skills, and gateway state.
- Profiles are Hermes home directories with their own config.yaml, .env, SOUL.md, memories, sessions, skills, and state database.
