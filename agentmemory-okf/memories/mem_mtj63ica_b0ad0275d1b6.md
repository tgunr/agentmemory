## Zed Editor with ZED-hosted Models vs Direct API Access

### **Zed's Pricing Structure**

- **Enterprise:** Custom pricing with additional features

**Zed's Per-Prompt Pricing (for usage beyond included limits):**
Claude 3.5 Sonnet: $0.04 per prompt, Claude 3.7 Sonnet: $0.04 per prompt, Claude Sonnet 4: $0.04 per prompt

For Max Mode models (unlimited tool calls): Claude 3.7 Sonnet: $0.05 per request, Claude Sonnet 4: $0.05 per request

### **Direct API Pricing**

**Anthropic Claude Models (Direct API):**
Claude 3.5 Sonnet: $3 per million input tokens and $15 per million output tokens, Claude Sonnet 4: $3 per million input tokens and $15 per million output tokens, Claude 3.7 Sonnet: $3 per million input tokens and $15 per million output tokens

**OpenAI Models (Direct API):**
GPT-4o: $5 per 1M input tokens and $20 per 1M output tokens, GPT-4o Mini: 60% cheaper than GPT-4o

### **Cost Analysis**

**When Zed is More Expensive:**
- **Heavy Usage:** If you're making many requests that generate substantial output, direct API access becomes significantly cheaper
- **Large Context:** For applications requiring extensive context or long outputs, token-based pricing is more economical
- **Example:** A typical prompt-response cycle might use 1,000 input + 2,000 output tokens = ~$0.033 via direct API vs $0.04-$0.05 via Zed

**When Zed is More Cost-Effective:**
- **Light to Moderate Usage:** The included prompts in Pro plan ($20/month for 500 prompts) = $0.04 per prompt, which can be competitive for smaller responses
- **Convenience Factor:** You can also pay someone else to use Zed's AI features. That is, you can bring your own API keys and they will Just Work with the new Agent Panel
- **No Setup Overhead:** Built-in integration without API key management

1. **Flexibility:** We currently support Amazon Bedrock, Anthropic, Github Copilot, Deepseek, Google AI, LM Studio, Mistral, Ollama, OpenAI and more - You can use your own API keys within Zed
2. **Rate Limits:** Zed's plans offer hosted versions of major LLM's, generally with higher rate limits than individual API keys
3. **Editor Features:** Zed is first and foremost a code editor with blazing-fast performance, true multiplayer collaboration, and a focus on developer productivity
