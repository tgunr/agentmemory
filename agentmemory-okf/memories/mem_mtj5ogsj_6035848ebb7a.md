### 🤖 Assistant

Here are some useful macOS apps for testing regular expressions:

1. **Regex101**: This is an online tool, but it can be accessed via any browser on macOS. It provides a detailed explanation of your regular expression and a real-time match highlighting.

2. **Patterns**: A dedicated macOS app for regex testing. It allows you to build and test regular expressions with a clean and simple interface.

3. **RegExRX**: This is another powerful regular expression editor for macOS. It provides extensive features for creating, testing, and debugging regular expressions.

4. **Expressions**: This app offers a minimalist interface for testing regular expressions. It supports syntax highlighting, match information, and a quick reference for regex syntax.

5. **Sublime Text**: While primarily a text editor, Sublime Text has powerful regex search and replace capabilities. You can use it to test regular expressions within text files.

6. **Visual Studio Code**: With the right extensions, VS Code can be a powerful tool for testing regular expressions. The "Regex Previewer" extension is particularly useful.

7. **RegexMagic**: This app provides a unique approach to creating regular expressions by letting you describe the patterns you want to match in plain English, and it generates the regex for you.

These tools should help you effectively test and debug regular expressions on macOS.
