How to display a list of open issues in Jira on a confluence page?

---

### 🤖 Assistant

To display a list of open issues from Jira on a Confluence page, you can use the Jira Issues Macro provided by Confluence. Here's how you can do it:

1. Edit the Confluence page where you want to display the list of open issues.
2. Click on the "+" icon in the toolbar to add a new macro.
3. In the macro browser, search for "Jira Issues" and select it.
4. Configure the macro settings:
   - Project or Saved Filter: Choose the Jira project or a saved filter that contains the open issues you want to display. You can also use JQL (Jira Query Language) to define a custom filter.
   - Display: Select the desired display option, such as table, list, or count.
   - Columns: Choose the columns you want to include in the display, such as summary, assignee, status, etc.
   - Sort: Define the sorting order for the issues if necessary.
   - Maximum Issues: Specify the maximum number of issues to display.
5. Once you have configured the macro settings, click "Insert" to add the macro to your Confluence page.
6. Save the Confluence page to see the list of open issues from Jira.

The Jira Issues Macro will fetch the relevant issues based on your configuration and display them on the Confluence page. Any updates or changes to the issues in Jira will be reflected automatically in the Confluence page, ensuring that the information remains up to date.

Note: To use the Jira Issues Macro, you need to have the necessary permissions in both Jira and Confluence, and the two applications should be properly integrated.
