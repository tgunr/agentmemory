### 👤 User

And on shape how do I use a SVG file to create a shape that I can transparently overlay into a part studio

---

### 🤖 Assistant

Got it—you’re working in Onshape and want to use an SVG to create a shape you can overlay transparently in a Part Studio. Here are a few ways to do that depending on what you need:

### If you want the SVG as sketch geometry (typical for creating features)
1. Prepare the SVG:
   - Use a vector-only SVG (no embedded raster images).
   - Simplify paths and convert text to outlines in your vector editor (e.g., Illustrator/Inkscape).
   - Prefer a single color; remove fills if you just need outlines.

2. Import the SVG:
   - In Onshape, open your Document → Insert dropdown → Import → upload your .svg.
   - Or directly in the Part Studio, start a Sketch on the plane/face where you want it.

3. Insert into a Sketch:
   - With a Sketch active: use Insert → DXF/DWG/SVG → select the uploaded SVG from the Document.
   - Set scale, rotation, and placement. If units seem off, adjust scale or resave the SVG with a known size.

4. Constrain and clean up:
   - Add dimensions/constraints as needed.
   - Close any tiny gaps

so profiles are watertight for features.

5. Create features:
   - Use Extrude, Cut, Emboss (if using a custom FeatureScript), etc., from the imported curves.

Note: Sketch entities are not “transparent overlays”—they’re editable curves. But you can leave the sketch visible for reference while modeling.

### If you want a visual transparent overlay (for tracing/reference)
Onshape doesn’t display SVGs as translucent images. For a transparent overlay look, use a PNG with transparency:

1. Convert SVG to PNG with alpha (transparent background) in your vector editor. Export at a high resolution for clarity.
2. In a Sketch, use Insert → Image and place the PNG on a plane/face.
3. Scale/position it, then trace with sketch entities. You can toggle sketch/image visibility as needed.

Tip: Lock the image with a Fix constraint so it doesn’t move while tracing.

### If you want a decal/appearance on a face
- Onshape doesn’t natively support image decals like some desktop CAD tools. Workarounds:
  - Create surface

geometry from the SVG (extrude very thin) and apply an appearance/color for a “logo” effect.
  - Or use the Render Studio (Enterprise/Pro add-on) for true decal workflows.

### Common pitfalls and fixes
- SVG imports tiny or huge: check export DPI or set a known reference dimension, then scale in Onshape.
- Curves broken or too dense: simplify paths before export; reduce node count.
- Text missing: convert text to outlines before export.
- Filled shapes not forming profiles: ensure outer and inner loops don’t self-intersect; remove fills and rely on outlines.

### Quick checklist
- Start Sketch → Insert → DXF/DWG/SVG → place and scale → constrain → use Extrude/Cut.
- For transparent overlay look: convert SVG to transparent PNG → Insert Image in Sketch → trace.

If you describe what you’re ultimately aiming for (e.g., cutout, emboss, logo reference), I can tailor the exact steps and settings.
