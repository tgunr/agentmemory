### 🤖 Assistant — 2025-03-08T13:46:21Z

Median and average (mean) are both measures of central tendency, but they work differently and can tell us different things about a dataset:

**Average (Mean)**:
- Calculated by adding all values and dividing by the number of values
- Influenced by extreme outliers
- Represents the "balance point" of the data
- Formula: (Sum of all values) ÷ (Number of values)

**Median**:
- The middle value when data is arranged in order
- Not affected by extreme outliers
- Represents the "middle point" of the data
- For an odd number of values: the middle value
- For an even number of values: average of the two middle values

**When to use which**:
- Use median when dealing with skewed data or outliers (like income distributions, house prices)
- Use average when data is symmetrically distributed without extreme outliers

**Example**:
For the dataset [1, 3, 3, 6, 7, 8, 9]:
- Average = (1+3+3+6+7+8+9) ÷ 7 = 37 ÷ 7 = 5.29
- Median = 6 (the middle value when arranged in order)

If we add an outlier: [1, 3, 3, 6, 7, 8, 9, 100]:
- Average jumps to 17.13
- Median only changes to 6.5 (average of 6 and 7)

This demonstrates why median is often preferred for economic data like incomes - it better represents what's "typical" when there are extreme values.
