## Best Git MCP Servers

There are several excellent Git MCP servers available, but the **official Anthropic Git MCP server** is the most recommended option:

### 1. **Official Anthropic Git MCP Server** (Recommended)
- **Package**: `mcp-server-git` (Python-based)
- **Maintained by**: Anthropic
- **Installation**: Uses `uvx` (recommended) or `pip`
- **Best for**: Local Git repository analysis and manipulation

### 2. **Official GitHub MCP Server** 
- **Package**: `@modelcontextprotocol/server-github` (TypeScript-based)
- **Maintained by**: Anthropic
- **Installation**: Uses `npx`
- **Best for**: GitHub API operations, remote repository management

### 3. **Community Alternatives**
- **codemcp**: Full coding assistant with Git integration
- **claude-code-mcp**: Integrates Claude Code as an MCP server

## Setup Instructions for Claude Desktop

Here's how to integrate the **official Git MCP server** with Claude Desktop:

### Prerequisites

1. **Install uv/uvx** (recommended method):
   ```bash
   # On macOS using Homebrew
   brew install uv
   
   # On Windows/Linux, follow instructions at: https://docs.astral.sh/uv/getting-started/installation/
   ```

2. **Alternative: Install Python and pip** if you prefer pip installation

### Configuration Steps

#### Step 1: Locate Claude Desktop Configuration File

**macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
**Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

#### Step 2: Add Git MCP Server Configuration

Add this configuration to your `claude_desktop_config.json` file:

```json
{
  "mcpServers": {
    "git": {
      "command": "uvx",
      "args": ["mcp-server-git", "--repository", "/path/to/your/git/repository"]
    }
  }
}
```

**For multiple repositories**, you can configure multiple servers:

```json
{
  "mcpServers": {
    "git-project1": {
      "command": "uvx",
      "args": ["mcp-server-git", "--repository", "/path/to/project1"]
    },
    "git-project2": {
      "command": "uvx",
      "args": ["mcp-server-git", "--repository", "/path/to/project2"]
    }
  }
}
```

#### Step 3: Optional - Add GitHub Integration

For remote GitHub operations, add the GitHub MCP server:

```json
{
  "mcpServers": {
    "git": {
      "command": "uvx",
      "args": ["mcp-server-git", "--repository", "/path/to/your/git/repository"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "your_github_token_here"
      }
    }
  }
}
```

To get a GitHub Personal Access Token:
1. Go to GitHub Settings → Developer settings → Personal access tokens
2. Generate a new token with `repo` scope for private repos or `public_repo` for public repos only
3. Copy the token and replace `your_github_token_here` in the configuration

#### Step 4: Restart Claude Desktop

Close Claude Desktop completely and restart it for the changes to take effect.
