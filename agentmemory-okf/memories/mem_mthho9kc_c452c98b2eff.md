### Key matching dimensions (from Bellofram Design Manual standard-size tables)
- **Class**: 4 (flat gasket-style flange for clamping between flat cylinder/cap or bonnet surfaces; most common/economical design; convolution formed by inverting the molded top-hat head corner at assembly).
- **Cylinder bore DC**: 2.37″ (very close to your 2.375″ / 60.3 mm; tolerances typically ±0.010″ per inch of diameter, min ±0.010″).
- **Piston DP**: ≈2.06″ (exactly listed in tables alongside 2.37″ DC sizes; your 2.06″ / 52.3 mm fits).
- **Height H**: Listed options include ≈1.00″, 1.12″ (directly matches your 1.0–1.2″ range). Height is chosen to support the required stroke (should not exceed DC).
- **Effective area Ae**: ≈3.6–4.1 in² range for these DC/DP combinations (your ~3.5–4.0 in² is consistent; Ae = π/4 × [(DC + DP)/2]² and stays constant while the diaphragm maintains a 180° convolution).
- **Half-stroke**: ≥15 mm (≈0.59″) is readily achievable. For Top-Hat style, required H ≈ SM + 2Rp + 1.56C + WF + Z (SM = max half-stroke; typical C/convolution width ~0.09–0.10″, Rp piston corner radius, WF flange thickness, Z safety factor ~0.10″ for this bore range). Tables list multiple H values supporting half-strokes well above 15 mm for these diameters.
- **Material**: Buna-N / Nitrile (NBR) on fabric reinforcement is standard/stock for many sizes (Bellofram code often “J” or similar for general-purpose oil-resistant Nitrile). Nylon fabric is available or substitutable (polyester is also common stock; fabric codes B/C etc. for strength). Double-coat constructions possible. Operating range typically –40 °F to +248 °F for standard Nitrile.<grok:render card_id="452ca0" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">75</argument></grok:render>

### Part-number style (Approximate Bellofram Code / ABC)
Format example: **4 – 237 – (206) – 112 – C ? J** (or similar)  
- 4 = Class  
- 237 = DC in hundredths of an inch  
- (206) = non-standard or specific DP if needed  
- 112 = H in hundredths  
- Sidewall thickness code (e.g., C ≈0.017″), fabric code, elastomer code (J = Nitrile), optional special-trim suffix.  

Exact current part numbers, tooling status (many nearby sizes marked “x” for available tooling), trim/perforations, and fabric confirmation require contacting Bellofram, as tables list both standard and special variants. Stock items are frequently Nitrile/polyester; custom nylon or other fabrics are quoted quickly.
