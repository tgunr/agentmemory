### 🤖 Assistant — 2026-08-06T15:20:50Z

**PopClip** is a popular macOS utility that displays a customizable popup menu of actions whenever you select text on your screen.<grok:render card_id="b163eb" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">0</argument></grok:render>

It works like an enhanced, context-aware version of the iOS/iPadOS text selection bar. Select any text in almost any app, and a floating bar appears with relevant options such as:

- Cut, Copy, Paste (including plain-text paste)
- Search (default Google, or other engines)
- Open Link (detects and opens URLs)
- Dictionary lookup
- Spelling suggestions
- And many more via built-in actions or extensions

Actions are context-sensitive (they only appear when relevant) and highly customizable—you can rearrange, rename, restyle, duplicate, or remove them. Extensions expand it further for tasks like translating text, converting case, sending to notes apps, running Shortcuts, looking up definitions on specific sites, and more.<grok:render card_id="295069" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">3</argument></grok:render>
