## OpenAPI Servers for PDF Processing

**Commercial Solutions:**

## MCP Servers for PDF Files

**Dedicated PDF MCP Servers:**
- **PDF Reader MCP** - A Node.js/TypeScript server that allows AI agents to read PDF files from local storage or URLs, extracting text, metadata, and page counts using pdf-parse
- **eBook-MCP** - Supports both EPUB and PDF formats, enabling natural language conversations with digital books. Offers smart library management and interactive reading experiences

**MCP Servers with PDF Support:**
- **AWS S3 MCP** - Flexibly fetches objects from S3 including PDF documents
- **FireCrawl MCP** - Advanced web scraping with JavaScript rendering and PDF support
- **Dicom MCP** - Specifically for querying and retrieving medical images and parsing DICOM-encapsulated PDF documents

## Key Features Available

**Text Extraction**: Most solutions can extract plain text from PDFs, with some preserving formatting and structure.

**OCR Support**: Several servers support optical character recognition for scanned PDFs.

**Metadata Extraction**: Many can retrieve document metadata like author, title, creation date, and page count.

**Advanced Processing**: Some solutions can extract tables, figures, and convert content to structured formats like JSON or Markdown.
