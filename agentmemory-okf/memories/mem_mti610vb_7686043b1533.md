APFS (Apple File System) supports multiple volumes within a single container, which makes this kind of setup possible. The key concept here is that you can have multiple bootable macOS installations on different APFS volumes within the same container, and then choose which one to boot from.

Let me provide a comprehensive answer about how to do this safely.You can set up a dual-boot configuration with APFS that allows you to switch between your current macOS and a beta version. Here's how to do it safely:

## Using APFS Volume Groups (Recommended Method)

**Step 1: Create a New APFS Volume**
1. Open Disk Utility
2. Select your APFS container (not the volume)
3. Click the "+" button and choose "Add APFS Volume"
4. Name it something like "macOS Beta" 
5. Choose "APFS" as the format
6. Set it to at least 60GB (more if you have space)

**Step 2: Install Beta macOS**
1. Download the beta installer from Apple Developer portal or Apple Beta Software Program
2. Run the installer and select your new APFS volume as the destination
3. Complete the installation process

**Step 3: Switching Between Systems**
- **Startup Manager**: Hold Option (⌥) key during boot to choose which volume to start from
- **System Preferences**: Go to System Preferences → Startup Disk to set your default boot volume
- **Command Line**: Use `sudo bless --mount /Volumes/[volume-name] --setBoot` to set default boot volume

## Important Considerations

**Before You Start:**
- **Create a full Time Machine backup** of your current system
- Ensure you have at least 60-80GB of free space
- Sign up for Apple Beta Software Program or have a developer account

**Benefits of APFS for This:**
- Both volumes share the same physical storage pool
- Space is allocated dynamically between volumes
- Fast switching between systems
- Both systems can access shared data volumes

**Potential Issues:**
- Beta software can be unstable
- Some apps may not work properly in beta
- You might encounter data compatibility issues between versions

**Recovery Options:**
- You can always delete the beta volume to reclaim space
- Your original system remains completely intact
- Time Machine backups work normally for both volumes
