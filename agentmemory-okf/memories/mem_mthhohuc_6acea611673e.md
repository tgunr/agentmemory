**Fireworks Fire Pass** (often written as “Fireworks Fire Pas”) is an experimental product from Fireworks AI. It gives access to selected open-weight models for personal agentic coding tools, with **no per-token charges** on the included models.<grok:render card_id="747411" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">20</argument></grok:render>

### What’s included
- Zero per-token costs on the enabled open-weight models (described as a powerful reasoning model with a large context window—up to ~1M tokens in some references—optimized for complex coding tasks).
- A dedicated Fire Pass API key (typically starting with `fpk_`) that works only for those open-weight models. Use your regular Fireworks key for everything else.
- Compatibility with OpenAI- and Anthropic-compatible agentic coding harnesses.

Supported tools include Claude Code, OpenCode, Cline, Kilo Code, OpenClaw, LangChain Deep Agents, and similar setups. For several of them, Fireworks recommends **FireConnect**, which automatically detects Fire Pass keys.<grok:render card_id="7ce1b6" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">20</argument></grok:render>

### Key model / endpoint details (as of recent docs)
- **Model ID**: `accounts/fireworks/routers/kimi-k3-fast` (check the official Fire Pass page for the latest enabled models, as they can change).
- **Base URL (OpenAI-compatible)**: `https://api.fireworks.ai/inference/v1`
- **Base URL (Anthropic-compatible)**: `https://api.fireworks.ai/inference` (some tools may need `/v1/messages` appended).

### How to get started
1. Create a Fireworks account at [app.fireworks.ai](https://app.fireworks.ai).
2. Go to the [Fire Pass page](https://app.fireworks.ai/fire-pass), review the details, and enter a promo/invite code. (It is currently invite-only; the pass activates immediately.)
3. Create a dedicated Fire Pass API key on the API keys page and configure it in your coding tool.

Usage of the covered models still appears in your dashboard for tracking, but the cost shows as $0.00 while the pass is active.<grok:render card_id="18e1ec" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">20</argument></grok:render>

### Important limitations
- **Personal / non-production use only** — intended for development, experimentation, and agentic coding harnesses. Production workloads are prohibited and can lead to the pass being revoked.
- Only the specifically enabled models are covered; other models on Fireworks are billed at normal rates.
- Features, availability, and pricing are subject to change (it is explicitly experimental).

Older public mentions described it as roughly $7/week (sometimes with a free first week) for unlimited access to a fast Kimi turbo model, but current official documentation emphasizes promo-code activation and zero per-token pricing for the included models.<grok:render card_id="413f06" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">24</argument></grok:render>
