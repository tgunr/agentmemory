To enforce that the job is a binding throughout all subviews in SwiftUI, you can pass the binding down through the view hierarchy. Here's how you can do it:

1. Ensure your parent view has the `@State` property for the job.
2. Pass the binding of this property to each subview that needs it using the `$` prefix.

Here's a simplified example:

```swift

    @State private var job: Job // Assuming `Job` is your model

    var body: some View {
        ChildView(job: $job)
    }
}
```
