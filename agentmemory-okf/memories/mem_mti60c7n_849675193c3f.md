## Status of CNC xPRO V5

The CNC xPRO V5 appears to be discontinued, with at least one Japanese distributor stating "CNC xPRO V5の再入荷の予定はございません。在庫がなくなり次第取り扱い終了となります" (No plans for restocking CNC xPRO V5. Sales will end when stock runs out). However, the xPRO V5 can run FluidNC firmware, though some sources note it's "GRBL32(Firmware) processor, which does not recommend to upgrade the firmware to FluidNC".

## Top FluidNC-Compatible Alternatives

### 1. **Bart Dring's 6x CNC Controller** (Recommended)
This is designed by Bart Dring, one of the original creators of FluidNC firmware. It can control 6 motors and many spindle and laser types, with integrated ESP32 controller and USB-C connector. Key features:
- (6) Motor connectors for external stepper drivers (5v signals) with separate step, direction and enable signals
- (8) Inputs for switches (limits, probes, control, etc)
- Multiple spindle support including RS485 VFD, 0-10V, PWM, relay-based, brushless motor (BESC), and laser PWM
- Available on [Tindie ($64)](https://www.tindie.com/products/33366583/6x-cnc-controller-for-fluidnc-integrated-esp32/) or [Elecrow ($49)](https://www.elecrow.com/6x-cnc-controller-for-fluidnc.html)

### 2. **4x CNC Controller with Built-in TMC2209 Drivers**
This is a 4 Axis CNC controller with (4) built in TMC2209 stepper motor drivers and a built in ESP32 module. The firmware has full control of the motor drivers via UART to set the microstepping, current and other features. Perfect if you need integrated drivers rather than external ones.

### 3. **SmartElectronic Compact CNC Controller**
A modular CNC controller for up to 6 high voltage stepper motors with embedded ESP32UE 8M memory. It supports both Grbl ESP32 and FluidNC firmware. Features:
- 10cm x 10cm compact size with ESP32UE 8MByte and external antenna
- Up to 50V DC power input support
- Modular design allowing customization as your machine evolves

### 4. **6 Pack CNC Controller with Integrated ESP32**
This is designed for people who want the highest level of flexibility in their controller, allowing your controller to evolve over time as your machine changes. It offers maximum modularity and customization options.

## Key Advantages of FluidNC Controllers

FluidNC includes a built-in browser-based Web UI so you can control the machine from a PC, phone, or tablet on the same Wifi network. There is no need to compile the firmware. You use an installation script to upload the latest release of the firmware and then create config file text file that describes your machine.

## Recommendation

For a direct replacement of the xPRO V5, I'd recommend **Bart Dring's 6x CNC Controller** as it offers the most comprehensive feature set, excellent community support, and comes from the FluidNC firmware creator himself
