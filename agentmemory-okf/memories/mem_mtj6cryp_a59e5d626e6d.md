Several macOS markdown apps can display Mermaid diagrams:

**Typora** - One of the most popular choices. It renders Mermaid diagrams inline as you type, with excellent support for flowcharts, sequence diagrams, Gantt charts, and more.

**Mark Text** - A free, open-source markdown editor that supports real-time Mermaid diagram rendering. It's lightweight and has a clean interface.

**Zettlr** - Academic-focused markdown editor with built-in Mermaid support. Great if you're doing research or academic writing.

**Obsidian** - While primarily a note-taking app, it has excellent Mermaid support through plugins and can handle complex diagram types.

**MacDown** - A simple, free markdown editor that supports Mermaid diagrams in its preview pane.

**Notion** (web/desktop app) - While not strictly a markdown app, it supports both markdown syntax and Mermaid diagrams natively.

For the best Mermaid experience, Typora is often recommended due to its seamless real-time rendering, though it's a paid app. If you prefer free options, Mark Text or MacDown work well. Obsidian is excellent if you want a more comprehensive note-taking system alongside your markdown editing.
