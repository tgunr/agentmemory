# Root Cause (likely pattern)
In similar tools I’ve fixed: **sync fired before connection & path resolution**, combined with `~` not expanded, so downloads silently no‑op (directory creation fails), or the remote list returns empty due to request before auth.

---

# Fix (Patch)
Below is a **minimal, safe** set of changes that typically resolves this class without changing public API.

1) **Ensure the path is valid and writable; expand `~`; create dirs.**  
2) **Defer sync until after “controller_connected”** OR **retry until connected**.  
3) **Make the sync idempotent** and loudly log mismatches.
