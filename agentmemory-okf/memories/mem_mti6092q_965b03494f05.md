## Finding the Maximum Z Height

The maximum Z height is defined in your **INI configuration file** in the `[AXIS_2]` section (Z axis is typically axis 2):

```ini
[AXIS_2]
MAX_LIMIT = 0.0    # Maximum Z position (typically 0 at top)
MIN_LIMIT = -150   # Minimum Z position (negative going down)
```

In LinuxCNC, the typical convention is:
- **Z = 0** is at the **top of travel** (maximum height)
- **Negative Z values** go **downward** from the top

You can also view the current axis limits in the AXIS GUI interface - they're displayed as a red dashed box showing the machine's travel limits.

## Moving Z to Maximum Position

To move the Z axis to its maximum height, use these methods:

### Method 1: MDI Command (Manual Data Input)
In the MDI tab, enter:
```gcode
G53 G0 Z0
```

### Method 2: If Your Max Limit is Different
If your `MAX_LIMIT` in the INI file is set to a different value (e.g., `MAX_LIMIT = 150`), then use:
```gcode
G53 G0 Z150
```

### Method 3: Using Machine Home Position
If you want to return to the exact home position:
```gcode
G28 Z0
```
(This moves Z to 0 first, then to the predefined G28 home position)

## Key Points About G53

- **G53** moves in **machine coordinate system** regardless of any work coordinate offsets (G54-G59.3)
