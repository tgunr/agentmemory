Telegram requires one unique number per account — there's no way to split your existing number, but you don't need a second SIM either. Three real routes:

**1. Cheapest reliable: rent a virtual number you control** (~$10–25/mo)
Services like Numero eSIM, Yesim, eSIMfly sell a *private* number that receives SMS in-app or via dashboard. Must be a dedicated number (not a shared "free SMS receive" page — anyone reading that page can steal the account, and Telegram often refuses those numbers or routes the code to the number's previous owner).
- Telegram → Settings → tap your profile → **Add Another Account** → enter the rented number → code from the service's app.
- Telegram allows up to **3 accounts** in one app, switchable with a tap.

**2. Free-ish: a data-only eSIM** (Keepgo, Airalo, etc.) if your iPhone has Dual SIM/eSIM headroom. Some carriers give a real MSISDN that can receive SMS; verify before buying.

**3. Official but expensive: a +888 collectible number from Fragment**
Telegram's own blockchain numbers, no SIM or carrier, code arrives on fragment.com. Downside: all 136k were sold out in 2022, so you buy from a reseller — the floor is currently roughly **300–2,600 GRAM (~$480–$3,500)**, plus 5% fee and sometimes Sumsub ID verification. Only worth it if you want zero carrier tie, not just a second account.
