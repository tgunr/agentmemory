### 🤖 Assistant

To add a single quote `"` with a space to your SUBSTITUTE line in the Vectric post processor, you would update it to:

```
SUBSTITUTE = "( ) \" "
```

The backslash `\` is used to escape the double quote character so it's treated as a literal character rather than ending the string.

Alternatively, if you need to substitute a double quote with a space (replace `"` with a space), the syntax would be:

```
SUBSTITUTE = "( ) \" "
```

Where:
- `\"` represents the double quote character you want to find
- The space after it is what you want to replace it with

If you meant substituting a single quote `'` instead, it would be:

```
SUBSTITUTE = "( ) ' "
```

### 👤 User

A double ", will this break things?

---

### 🤖 Assistant

In Vectric post processors, using a double quote `"` inside a `SUBSTITUTE` string can indeed be tricky because the post processor uses double quotes to define the start and end of the substitution string itself.

If you write `SUBSTITUTE = "( ) " "`, the software will likely see the second quote as the end of the command and the third quote as a syntax error, which will cause the post processor to fail or ignore the line.

To safely substitute a double quote with a space, you should use the **hexadecimal code** for the double quote character, which is `\x22`. This prevents the software from getting confused by the literal quote mark.

Your updated line should look like this:

```
SUBSTITUTE = "( ) \x22 "
```

In this format:
- `( )` replaces parentheses with spaces.
- `\x22 ` replaces the double quote `"` with a space.

This is the standard "safe" way to handle special characters in Vectric configuration files without breaking the code structure. Would you like me to check if there are any other special

The way to handle this in Vectric is:

### 1. Don’t try to use `SUBSTITUTE` for `"`
`SUBSTITUTE` in Vectric posts only supports simple text strings, and `"` conflicts with the string delimiters. There’s no escape sequence, so you can’t reliably say “replace `"` with space” on that line.

### 2. Remove parentheses using `SUBSTITUTE`
This part *does* work and is safe. For example, to turn `(` and `)` into spaces:

```text
SUBSTITUTE = "( )"
```

```text
SUBSTITUTE = "("
```
