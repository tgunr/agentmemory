### Part Number Breakdown (ABC# format)
From the Bellofram Design Manual, diaphragms use this coding:<grok:render card_id="28b4d5" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">67</argument></grok:render>

- **4** = Class 4 (most common design; flat flange for clamping between cylinder and cap/bonnet; fabric in intimate contact with metal for high-pressure sealing; convolution formed by inversion at installation).
- **225** = Cylinder bore diameter (DC) = 2.25 inches.
- **(206)** = Piston diameter (DP) = 2.06 inches (shown in parentheses when non-standard or as listed).
- **094** = Height (H for “top hat” style, or K for “C” style) = 0.94 inches.
- **C** = Sidewall thickness (WSW) code ≈ 0.017" ± 0.003".
- **xx** = Fabric code + elastomer code (and any special trim suffix such as -1). These must be specified for the exact compound (e.g., polyester fabric + neoprene, Viton, silicone, etc.).

The “X” (or “x”) in the description indicates a **standard size with existing tooling available**.<grok:render card_id="b2518e" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">0</argument></grok:render>

### Key Dimensions (from standard size tables)
Matching entries appear in the Class 4 / Class 4C standard size tables in the design manual (e.g., DC 2.25 / DP 2.06 / height around 0.94). Typical associated values for this size range include convolution width, effective area, and half-stroke limits consistent with the height.<grok:render card_id="9fb72b" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">0</argument></grok:render>

**Tolerances** (general for this DC range of 1.00–2.50"):
- DC and DP: ±0.010" per inch of diameter (min ±0.010", max ±0.060").
- Height: typically no less than ±0.015" or ±0.015" per inch of height.
- Other dimensions (flange thickness WH/WF, radii, etc.) follow the Class 4 tables.<grok:render card_id="6253ae" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">68</argument></grok:render>

### Class 4 Characteristics
- Economical hardware design for flat mating surfaces.
- Flange primarily acts as a gasket; supports high pressures because the fabric is clamped directly.
- Convolution is formed by inverting the head corner radius during installation (a curved-lip retainer plate is recommended to prevent re-inversion).
- Suitable for a wide range of pressures (up to thousands of psi depending on materials), temperatures (roughly –120 °F to +600 °F depending on elastomer/fabric), and strokes.<grok:render card_id="6a6f82" card_type="citation_card" type="render_inline_citation"><argument name="citation_id">2</argument></grok:render>

For exact material options (fabric strength codes such as B/C/P, elastomer compounds, chemical resistance, working pressure, trim/perforation, or a quote), contact Bellofram Elastomers / Marsh Bellofram (Newell, WV; 1-800-727-5646 or belloframelastomers.com / marshbellofram.com) with the full ABC# including the fabric and elastomer codes. The design manual PDF (available on their site) contains full standard-size tables, formulas for required height vs. stroke, hardware design guidelines, and elastomer data.
