It sounds like you’re asking about the correct **IMAP** (for receiving mail) and **SMTP** (for sending mail) host settings for Apple Mail when using an iCloud/Apple email account. Here are the current standard settings:

- **Server name (host):** `imap.mail.me.com`  
- **Port:** 993  
- **Encryption:** SSL/TLS  
- **Username:** Your full iCloud email address (e.g., `username@icloud.com`)

### Outgoing Mail (SMTP)
- **Server name (host):** `smtp.mail.me.com`  
- **Port:** 587 (preferred) or 465  
- **Encryption:** STARTTLS (587) or SSL/TLS (465)  
- **Username:** Same as above (full iCloud email address)  
- **Password:** Same app-specific password  

🔑 **Important:** If you have two-factor authentication enabled on your Apple ID, you’ll need to generate an **app-specific password** from your Apple ID account page ([appleid.apple.com](https://appleid.apple.com)) and use that instead of your main Apple ID password.
