### 👤 User

In Etsy, I have several variations of a military patch, each one that can be customized with the model of the aircraft. How can I create a listing that the user can select which patch and which model they want to use?

---

### 🤖 Assistant

To set up a listing on Etsy that allows customers to choose both a specific patch design and a specific aircraft model, you should use Etsy's **Variations** feature. This allows you to offer different options within a single listing so customers don't have to message you separately with their choices.

### Step 1: Enable Variations
When you are creating or editing your listing, scroll down to the **Inventory and Pricing** section. Look for the **Variations** button and click **Add variations**.

### Step 2: Create the First Variation (The Patch)
Etsy provides standard categories like "Primary color" or "Size," but for your specific needs, you should choose **Create a new variation** from the dropdown menu. Name this variation something clear, such as "Patch Design" or "Patch Style." You can then list the different military patches you offer (e.g., "Squadron A," "Squadron B," "Vintage Wing").

### Step 3: Create the Second Variation (The Aircraft Model)
Click **Add a second variation**. Again, choose **Create

a new variation** and name it "Aircraft Model." Here, you can list the specific models available for customization, such as "F-16 Fighting Falcon," "A-10 Warthog," or "C-130 Hercules."

### Step 4: Manage Photos and Pricing
One of the most helpful features for buyers is the ability to link photos to variations. In the variation settings, check the box that says **Link photos to this variation**. This allows you to assign a specific image to each "Patch Design" so that when a customer selects a style from the dropdown, the corresponding photo automatically pops up.

If certain aircraft models or patch designs cost more to produce, you can also check the boxes for **Prices vary for each...** or **Quantities vary for each...** to manage your inventory and pricing at a granular level.

### Step 5: Use the Personalization Field (Optional)
If you have a massive list of aircraft models that exceeds Etsy's limit of 70 options per variation, or if you want to allow customers to type in a specific tail number or

custom text alongside the model, you should enable the **Personalization** toggle. You can provide instructions like: "Please enter the aircraft model and any specific tail number you would like embroidered."

### Summary of Best Practices
*   **Limit of Two:** Etsy only allows a maximum of two variation types per listing. If you need a third (like "Thread Color"), you will need to use the Personalization box for that extra information.
*   **Clear Naming:** Ensure your variation names are intuitive so customers don't get confused about what they are selecting.
*   **Combined Options:** If you find the two-variation limit restrictive, some sellers combine options into one list (e.g., "Patch A - F16," "Patch A - A10," etc.), though this can become a very long list quickly.
