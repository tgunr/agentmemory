### 🤖 Assistant

Sure, here's a simple Arduino sketch that accomplishes this. 

```cpp
const int pin = 1;
unsigned long startTime;
unsigned long duration;

void setup() {
  // Start the serial communication
  Serial.begin(9600);
}

void loop() {
  // Set the pin to OUTPUT
  pinMode(pin, OUTPUT);
  digitalWrite(pin, HIGH);
  delay(1000); // Wait for 1 second

  // Switch the pin to INPUT
  pinMode(pin, INPUT);
  startTime = micros(); // Start the timer

  // Wait for the pin to go LOW
  while (digitalRead(pin) == HIGH);

  // Calculate the duration it took to go from HIGH to LOW
  duration = micros() - startTime;

  // Print the duration to the serial monitor
  Serial.print("Duration: ");
  Serial.println(duration);
  delay(1000); // Wait for 1 second before repeating the loop
}
```

This code sets the digital I/O pin 1 to an output, then switches it to an input and times the duration it goes from HIGH to LOW. The duration is then printed to the serial monitor.

Please note that this code assumes that there is some external circuitry that will pull the pin LOW after it has been set to INPUT. If there is no such circuitry, the pin will remain HIGH indefinitely because of the internal pull-up resistor.

Also, keep in mind that pin 1 is typically used for serial communication (TX), so using it for general I/O might interfere with serial communication, including uploading sketches and printing to the serial monitor. If you're having trouble, try using a different pin.
