# 8x8" CNC Vacuum Table - Design Specifications

## Overview

A shop-built vacuum table designed to hold workpieces securely during CNC routing operations, allowing full-thickness edge cuts without damaging the main table structure. Compatible with AirWeights 5 CFM vacuum pump and grid gasket system.

---

## Design Philosophy

**Three-Layer System:**
1. **Base Plenum** - Sealed vacuum chamber for air distribution
2. **Middle Grid Plate** - Semi-permanent layer with vacuum distribution holes
3. **Sacrificial Top** - Replaceable surface that takes router damage

This allows cutting through material completely while only damaging the cheap, replaceable top layer.
