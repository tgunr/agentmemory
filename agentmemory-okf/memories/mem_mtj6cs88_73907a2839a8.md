**Tool Knowledge**

When using desktop-commander for SSH connections to remote servers, the syntax `ssh root@hostname 'command'` works reliably for executing single commands on remote systems. For Samba troubleshooting, the command sequence `systemctl status smbd`, `testparm -s`, and `ls -la /path/to/share` provides comprehensive service status, configuration validation, and directory verification. The `pdbedit -L` command effectively lists Samba users to verify authentication setup. When editing configuration files remotely, `sed -i "s|old_path|new_path|g" /etc/samba/smb.conf` successfully performs path corrections, followed by `systemctl restart smbd` to apply changes. For network connectivity testing from Mac to SMB servers, `smbutil view //IP_ADDRESS` provides better results than hostname-based connections when DNS resolution issues exist. The `tmutil destinationinfo` command reveals current Time Machine configuration and can identify when local backup drives are already configured alongside network destinations.
